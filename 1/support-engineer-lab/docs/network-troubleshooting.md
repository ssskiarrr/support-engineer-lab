# Network Troubleshooting

## Базовый порядок

### 1. Интерфейсы и IP
```bash
ip addr
ip route
```

### 2. DNS
```bash
nslookup example.com
```

Если доменное имя не резолвится, но IP доступен — вероятна проблема DNS.

### 3. Доступность узла
```bash
ping 8.8.8.8
```

### 4. Маршрут
```bash
traceroute example.com
```

### 5. Порт
```bash
nc -vz example.com 443
ss -tulpn
```

### 6. HTTP
```bash
curl -v https://example.com
```

## Что важно понимать

- DNS преобразует имя хоста в IP.
- ARP используется внутри локальной сети для сопоставления IPv4 и MAC.
- Router передаёт пакеты между сетями.
- NAT изменяет адреса при прохождении трафика между сетями.
- TCP использует соединение и подтверждение доставки.
- UDP не устанавливает соединение и имеет меньшие накладные расходы.
